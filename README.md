# Арена переговоров

Тренажёр деловых переговоров в формате диалоговой игры. Вы ведёте разговор с руководителем, клиентом или поставщиком, на каждом шаге выбираете реплику, и исход (успех, компромисс или провал) зависит от стратегии и формулировок. После разговора — разбор: какие переговорные техники сработали, какие нет, и как можно было сказать сильнее.

![Диалог с менеджером поставщика: собеседник доволен сильным ответом, ниже — варианты следующей реплики](docs/images/dialogue.jpg)

Решение для кейса ОЭЗ «Алабуга» на хакатоне «Лидеры цифровой трансформации» (ЛЦТ) 2026. Техническое задание — [`9. ОЭЗ ППТ Алабуга.pdf`](9.%20ОЭЗ%20ППТ%20Алабуга.pdf).

## Попробовать

**В браузере (без установки):** https://masterit.itch.io/arena-peregovorov-lc

- Рекомендуемый браузер — Google Chrome или Microsoft Edge на компьютере. Интернет нужен только для загрузки страницы; дальше игра работает без сети и без внешних сервисов.
- Первая загрузка — около 70 МБ, пока идёт полоса загрузки.
- Кнопка в правом верхнем углу открывает игру на весь экран.

**Windows:** скачайте архив `ArenaPeregovorov-Windows.zip` на той же странице itch.io, распакуйте целиком и запустите `ArenaPeregovorov.exe`. Установка не нужна. Если Windows покажет окно SmartScreen «Неизвестный издатель» (файл не подписан), нажмите «Подробнее» → «Выполнить в любом случае».

Ключи API, аккаунты и настройка окружения не нужны: в игре нет сервера и нет обращений к внешним сервисам.

## Как пройти ключевой сценарий (около 5 минут)

1. **Главное меню → «Настройки администратора».** Это интерфейс тренера, где задаётся контекст.
2. **Задайте контекст.** Уровни навыков игрока (Напор, Эмпатия, Логика — от 1 до 3), сфера (HR, Закупки, B2B-продажи), сложность и тон собеседника. Внизу сразу видно, какой сценарий подобран и кто оппонент; при смене настроек подбор меняется. Нажмите «Начать переговоры».
3. **Ведите диалог.** Выбирайте ответ мышью или клавишами 1–9. Серые реплики недоступны при текущих навыках — рядом иконка навыка и нужный уровень. Портрет и подпись над репликой показывают реакцию собеседника на ваш последний ход.
4. **Получите разбор.** Исход, профиль переговорщика, баллы по техникам, динамика разговора, сильные стороны и «над чем поработать» — с цитатами ваших реплик и более сильными формулировками. Кнопка «Теория и техники» открывает справочник по всем 15 техникам.
5. **Сравните.** «Пройти ещё раз» — тот же сценарий другой стратегией; «Другой сценарий» — вернуться к настройкам и выбрать другую сферу, сложность или тон.

Два других входа из главного меню:

- **«Тренировка»** — сразу в лёгкий сценарий, без настроек.
- **«Тестирование»** — тест навыков из 18 утверждений (около 2 минут), затем рекомендованный сценарий под ваш уровень.

В браузерной версии нет кнопки возврата в главное меню: чтобы начать с начала, обновите страницу (F5). В Windows-версии эти кнопки в правом верхнем углу (выход и «в меню»).

## Сборка из исходников

### Что понадобится

- [Unity Hub](https://unity.com/download) и редактор **Unity 6000.3.23f1** (Unity 6.3 LTS) с модулем **WebGL Build Support** и/или **Windows Build Support**. Подойдёт бесплатная лицензия Unity Personal.
- **Git** и **[Git LFS](https://git-lfs.com)** — картинки и звуки хранятся в LFS; без него вместо них скачаются текстовые заглушки.
- Python 3.10+ — только для вспомогательных скриптов (проверка сценариев, подготовка ассетов), для запуска игры не нужен.

### Получить проект

```bash
git lfs install
git clone https://github.com/Kajjc/-.git arena-peregovorov
cd arena-peregovorov
git lfs pull
```

### Запустить в редакторе

1. Unity Hub → **Add** → выберите папку `unity` внутри репозитория.
2. Откройте проект (первое открытие — несколько минут на импорт).
3. Откройте сцену `Assets/Scenes/Main.unity` и нажмите **Play**.

Весь интерфейс строится кодом при запуске, поэтому в сцене почти пусто — так и должно быть.

### Собрать из командной строки

Команды запускаются из корня репозитория, путь к Unity — стандартный для Windows. Редактор Unity при этом должен быть закрыт.

```bat
:: WebGL -> unity/WebGL-Build/
"C:\Program Files\Unity\Hub\Editor\6000.3.23f1\Editor\Unity.exe" -batchmode -quit -projectPath unity -executeMethod Arena.EditorTools.BuildScript.BuildWebGL -logFile build-webgl.log

:: Windows -> unity/Windows-Build/ArenaPeregovorov.exe
"C:\Program Files\Unity\Hub\Editor\6000.3.23f1\Editor\Unity.exe" -batchmode -quit -projectPath unity -executeMethod Arena.EditorTools.BuildScript.BuildWindows -logFile build-windows.log
```

То же доступно из редактора: **File → Build Profiles**.

WebGL-сборку нельзя открыть двойным щелчком по `index.html` — браузер не загрузит файлы игры по `file://`. Запустите локальный сервер и откройте http://localhost:8000:

```bash
cd unity/WebGL-Build
python -m http.server 8000
```

Для загрузки на itch.io упакуйте содержимое папки так, чтобы `index.html` лежал в корне архива:

```bash
cd unity/WebGL-Build
python -m zipfile -c ../ArenaPeregovorov-WebGL.zip index.html Build TemplateData
```

Не используйте для этого `Compress-Archive` из PowerShell 5.1: он может записать пути с обратным слэшем, и itch.io не найдёт файлы во вложенных папках. Сжатие WebGL в проекте отключено намеренно — статические хостинги не всегда отдают сжатые файлы с правильными заголовками.

### Проверить сценарии

```bash
python scripts/validate_scenario.py unity/Assets/Resources/Scenarios/*.json
```

Скрипт проверяет, что все переходы ведут в существующие узлы, все узлы достижимы, у каждого финала есть исход и итоговый текст, техники и баллы соответствуют таксономии, а у каждой слабой реплики есть более сильная альтернатива. Нужен только стандартный Python.

## Что внутри

| Путь | Что там |
|---|---|
| `unity/Assets/Scripts/Dialogue/` | Движок: модель сценария, обход дерева, проверка навыков, подсчёт баллов, подбор сценария |
| `unity/Assets/Scripts/UI/` | Экраны: меню, тест навыков, настройки, диалог и разбор, справочник по техникам |
| `unity/Assets/Scripts/Bootstrap/` | Точка входа и переходы между экранами |
| `unity/Assets/Resources/Scenarios/` | 18 сценариев в JSON (6 сюжетов × 3 уровня сложности) |
| `unity/Assets/Resources/TechniqueTaxonomy.json` | 15 переговорных техник с определениями и источниками |
| `unity/Assets/Editor/` | Скрипты сборки, настройки брендинга и автоимпорта ассетов |
| `unity/Assets/WebGLTemplates/Arena/` | Страница загрузки для браузерной версии |
| `scripts/` | Python: проверка сценариев, подготовка портретов, иконок, логотипа и звуков |
| `assets-src/` | Исходные записи голосов (в сборку не входят) |
| `docs/` | Документация |
